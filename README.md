##Student Registration Form

A clean and responsive student registration form built using HTML and CSS. This project demonstrates form structure, input handling, and basic UI design.

---

##Features

- User-friendly form layout
- Input fields for personal, contact, and academic details
- Radio buttons, checkboxes, dropdowns
- File upload support
- Form validation using HTML attributes
- Clean and responsive design

---

##Technologies Used

- HTML5
- CSS3

---

- `index.html` – Main file containing structure and styling
